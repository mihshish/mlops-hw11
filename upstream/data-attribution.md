# Источник и преобразования данных

Исходный набор: **Russian NMO Medical MCQ**, публикация **drkolesnikov**:
https://huggingface.co/datasets/drkolesnikov/russian-nmo-medical-mcq

На карточке источника указана лицензия **CC-BY-4.0**:
https://creativecommons.org/licenses/by/4.0/

В ДЗ 3 из исходного sft_single выбран тематический набор неотложной помощи,
очищены дубли, темы распределены между train/val/test. В ДЗ 4 train/val
токенизированы для Qwen3-0.6B. В ДЗ 6+7 использованы те же тензоры;
из held-out test отобраны 50 вопросов, добавлены именованные срезы и
строковые метки choices для строгой JSON-оценки. Эталонная числовая метка
сохранена из исходного correct_choice_indices и сверена с текстом ответа.

Три behavioral-кейса подготовлены для этой работы: исходный вопрос о
группе крови, его перефраз с перестановкой вариантов и авторский запрос
вне предметной области. Эти изменения описаны в полях source/review.
Полный train-index содержит исходные формулировки для контроля пересечений.
Хеши конкретных локальных parquet и файлов пайплайна — data-lineage.json.

Ни автору исходного набора, ни составителям клинических рекомендаций не
приписывается одобрение данной модели или её ответов. Публикуется учебная
переработка с указанием источника; независимую клиническую верификацию
50 меток или пригодность модели для практической медицины не заявляем.
